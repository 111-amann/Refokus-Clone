# Refokus Clone

A modern, high-performance Refokus-inspired website built using React, Locomotive Scroll, and Framer Motion.

## 🚀 Live Demo

🔗 [View Project](https://github.com/111-amann/Refokus-Clone)

## 🛠 Technologies Used

- **React** – Component-based UI development
- **Locomotive Scroll** – Smooth scrolling animations
- **Framer Motion** – Powerful animations and transitions
- **React-DOM** – DOM rendering for React
- **React-Icons** – Scalable vector icons

## 📦 Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/111-amann/Refokus-Clone.git
   ```
2. Navigate to the project directory:
   ```sh
   cd Refokus-Clone
   ```
3. Install dependencies:
   ```sh
   npm install
   ```
4. Start the development server:
   ```sh
   npm start
   ```
